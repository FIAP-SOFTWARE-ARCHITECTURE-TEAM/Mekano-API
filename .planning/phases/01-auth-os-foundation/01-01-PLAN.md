## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | POST /auth/login | mitigate | BCrypt password verification; 401 for invalid credentials (same message for user not found vs wrong password) per D-08 |
| T-01-02 | Tampering | JWT signing | mitigate | Ed25519/EdDSA algorithm; private key at ~/.mekano/secrets/ with restricted permissions; public key committed for verification |
| T-01-03 | Info Disclosure | Refresh token | mitigate | Token stored as SHA-256 hash; rotation invalidates old token on each use; PESSIMISTIC_WRITE lock prevents race condition |
| T-01-04 | Tampering | @RolesAllowed bypass | mitigate | SmallRye JWT enforces claims from signed token; `mp.jwt.verify.publickey.algorithm=EdDSA` prevents algorithm confusion |
| T-01-05 | DoS | POST /auth/login | mitigate | Existing TokenBucketRateLimiter handles 10 attempts/min per email+IP |
| T-01-SC | Tampering | Maven dependencies | mitigate | All deps from io.quarkus group, BOM-managed by quarkus-bom — no external packages |
</threat_model>
