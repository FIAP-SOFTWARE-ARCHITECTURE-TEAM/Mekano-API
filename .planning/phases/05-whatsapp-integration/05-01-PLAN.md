    **Create `WhatsAppOrcamentoObserver.java`**

    Package: `com.fiap.mekano.infrastructure.observer`

    `@ApplicationScoped`, constructor injection receiving:
    - `WhatsAppNotifierPort notifier`
    - `OrdemDeServicoRepositoryPort osRepository`
    - `ClienteRepositoryPort clienteRepository`
    - `OrcamentoRepositoryPort orcamentoRepository` (need to check if this exists — it does per domain AGENTS.md)

    **CRITICAL: NO `@Transactional` annotation.** Per D-11 and RESEARCH.md Pitfall 2: observers that call external HTTP services must NOT hold DB connections. This observer only reads from repositories and calls an HTTP API — no DB writes. If reading requires a transaction context (Hibernate lazy loading), use `@Transactional(Transactional.TxType.REQUIRES_NEW)` on a separate internal method, or ensure all reads complete before the HTTP call. **Preferred approach:** keep the observer non-transactional and use `@Transactional(value = Transactional.TxType.REQUIRED, rollbackOn = Exception.class)` only on a `@Transactional`-annotated private helper that performs DB reads, if Hibernate lazy-loads fail without a transaction. Test this — if `findById` works without `@Transactional` (because Quarkus/Arc may auto-open a session), leave it off entirely.

    ```java
    void aoFinalizarDiagnostico(@Observes(during = TransactionPhase.AFTER_SUCCESS) DiagnosticoFinalizadoEvent event) {
        // 1. Resolve OS → cliente UUID
        var os = osRepository.findByUuid(event.osUuid())
                .orElseThrow(() -> new AppException(404, Messages.get("os.nao.encontrada", event.osUuid())));

        // 2. Resolve cliente → Telefone
        var cliente = clienteRepository.findByUuid(os.getClienteId())
                .orElseThrow(() -> new AppException(404, Messages.get("cliente.nao.encontrado", os.getClienteId())));

        if (cliente.getTelefone() == null) {
            log.warn("Cliente {} não possui telefone cadastrado — ignorando notificação WhatsApp", cliente.getId());
            return;
        }

        // 3. Resolve orçamento to get valorTotal
        var orcamento = orcamentoRepository.findByOsUuid(event.osUuid())
                .orElseThrow(() -> new AppException(404, Messages.get("orcamento.nao.encontrado", event.osUuid())));

        // 4. Send notification
        notifier.notificarOrcamento(
                cliente.getTelefone().getValue(),
                cliente.getNome(),
                orcamento.getId(),
                orcamento.getValorTotal());
    }
    ```

    Import `jakarta.enterprise.event.TransactionPhase` and use `@Observes(during = TransactionPhase.AFTER_SUCCESS)` — per D-11 explicit decision. This ensures the notification fires only after the DB transaction that published the event successfully commits.

    Log the notification attempt with masked phone (use same `maskPhone` pattern from Task 1).

    **IMPORTANT:** The observer method must be `void` and package-private (no `public`).
