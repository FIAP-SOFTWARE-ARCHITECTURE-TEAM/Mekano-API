<objective>
Refatorar o root `pom.xml` de um scaffold Quarkus single-module para um aggregator POM multi-módulo, e deletar todos os arquivos scaffold que serão substituídos pela estrutura de módulos.

**Por que é crítico:** Nenhum outro plano pode executar sem esta refatoração. O `<packaging>quarkus</packaging>` no root causa falhas silenciosas no build multi-módulo. O `quarkus-maven-plugin` no root viola G1 (Gotcha 1) e quebraria CDI em todos os módulos.

**Output:**
- `pom.xml` refatorado: packaging=pom, modules declarados, dependencyManagement com BOM + libs, pluginManagement com plugins gerenciados
- Scaffolding removido: 3 arquivos Java + 1 application.properties
</objective>
