<objective>
Rename PT-BR method names to English in 3 repository ports and all call sites

**Purpose:** The project has inconsistent naming — 4 repository ports (User, Cliente, Veiculo, Servico) use English (`save`, `findById`), while 3 ports (Peca, NfEntrada, RequisicaoCompra) use Portuguese (`salvar`, `buscarPorId`). This plan standardizes to English for consistency (per D-05).

**VERIFIED:** PecaService, NfEntradaService, and RequisicaoCompraService already use constructor injection (NOT field injection). ClienteService.updateCliente ALREADY applies field updates. NfEntradaRepositoryImpl uses correct getters (NOT the copy-paste bug). These items require NO work.

**Output:**
- 3 port interfaces renamed: `salvar()` → `save()`, `buscarPorId()` → `findById()`
- 3 repository implementations updated
- 3 service classes updated (including service-level `buscarPorId()` method renames)
- 3 resources + 3 test files updated
</objective>
