  <action>
    **Update `.dockerignore`:**

    Replace the current whitelist-based .dockerignore with a simpler blacklist that excludes everything the build doesn't need. The Dockerfile.jvm multi-stage build compiles JAR inside the container — the build context only needs source code and pom.xml files.

    ```dockerignore
    # Mekano .dockerignore — exclude build context noise
    .git/
    .gitignore
    .github/
    .env
    .env.example
    .idea/
    .vscode/
    *.md
    **/target/
    *.pem
    *.postman_collection.json
    docker-compose*.yml
    ```

    Rationale:
    - `**/target/` — Prevents local build artifacts from entering context (cache pollution, large size). The container build generates target/ from source.
    - `.git/` — Avoids copying entire git history (can be 50-100MB)
    - `.github/` — CI configs not needed inside container
    - `*.md`, `.env*` — Documentation and local env files not needed at runtime
    - `*.pem` — Keys must come from mekano_secrets volume, never from build context
    - `docker-compose*.yml` — Compose files are for orchestration, not inside the image

    **Update `.env.example` (per D-04):**

    Replace the 2-line file with a comprehensive documented template:

    ```env
    # Mekano — Environment Variables
    # Copy this file to .env and adjust values
    #   cp .env.example .env
    #
    # WARNING: Never commit .env to git (it's in .gitignore)

    # --- PostgreSQL ---
    # Default user/password for dev; change for production
    POSTGRES_USER=mekano
    POSTGRES_PASSWORD=mekano

    # --- Docker Compose ---
    # Project name for container/volume prefixing
    COMPOSE_PROJECT_NAME=mekano
    ```

    DO NOT include JWT_KEY variables — the keygen service generates them automatically per D-03/O the agent's discretion.
  </action>

    ## Troubleshooting

    ### Porta 5432 já em uso

    Se o PostgreSQL local estiver rodando na porta padrão:

    # Mapear porta host diferente (5433 → 5432 container)

    ```bash
    # ATENÇÃO: Apaga todos os dados!
    docker compose down -v && docker compose up -d
    ```

    ### Build lento (dependências Maven baixando do zero)

    ```bash
    # Rebuild sem cache
    docker compose build --no-cache mekano

    # Ou compile o JAR localmente primeiro e depois use a imagem:
    ./mvnw package -pl mekano-rest -am -DskipTests
    docker compose build mekano
    ```

    ### Verificar logs da aplicação

    ```bash
    docker compose logs -f mekano
    docker compose logs postgres
    docker compose logs keygen
    ```

    ```bash
    # Verificar se as chaves foram geradas
    docker compose run --rm -v mekano_secrets:/secrets alpine ls -la /secrets/

    # Se vazio, forçar regeração
    docker compose run --rm -v mekano_secrets:/secrets alpine rm -f /secrets/privatekey.pem /secrets/publicKey.pem
    docker compose up -d keygen
    ```

    # docker-compose.yml → environment → QUARKUS_PROFILE: dev
